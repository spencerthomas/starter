# Product sense

Begin with the person using the result and the decision or task it supports. For analysis, define the question, population, timeframe, and decision criterion. For a feature, define the user journey and observable behavior. For knowledge work, define the audience, evidence standard, and deliverable.

Record these in a brief under [product-specs](product-specs/index.md). Make scope and unresolved assumptions explicit. Prefer a useful, testable first result over a speculative roadmap.
