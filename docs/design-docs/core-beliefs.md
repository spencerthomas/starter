# Core beliefs

- Give the next agent a map and a concrete outcome, then let it retrieve detail as needed.
- Keep decisions, evidence, and runnable checks near the artifacts they govern.
- Start small. A new folder, dependency, rule, or agent needs an actual job.
- Preserve source provenance; keep observation, inference, and recommendation distinct.
- Verify outcomes at the point people consume them: execute code, inspect data, render documents, and exercise interfaces.
- Make collaboration legible through explicit ownership and useful handoffs.
- Turn repeated friction into a small improvement to the environment.
