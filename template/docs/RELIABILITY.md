# Reliability

Record the commands and inputs needed to reproduce meaningful results. Pin dependencies when they are introduced. Validate external data at ingestion, preserve original inputs, and make failures visible.

For analysis, check grain, units, missingness, duplicates, time coverage, and joins before drawing conclusions. For code, add checks around real failure modes and record run/build/test commands. For documents and decks, inspect the rendered deliverable.

When generating an artifact, record inputs, method or command, date, and limitations beside the artifact or in the relevant spec. Add operational procedures only when an actual service or recurring job exists.
