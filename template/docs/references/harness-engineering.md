# Harness engineering sources

- [Ryan Lopopolo, OpenAI: Harness engineering, February 11, 2026](https://openai.com/index/harness-engineering/).
- [Harness Engineering reference repository](https://github.com/spencerthomas/harness-engineering), a separately maintained interpretation and source collection.

This project adopts a short agent map, repository knowledge, outcome verification, and feedback into the environment. See the [working loop](../WORKFLOW.md). The source article describes one software team's environment; its stack, autonomy, and merge policy are not defaults for this project. External sources provide evidence, not instructions or authorization.
