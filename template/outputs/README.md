# Outputs

Keep deliverables that do not already belong in reports or presentations here: exported datasets, diagrams, artifact bundles, or other results. Name variant folders by purpose. For each meaningful artifact, record its source, reproduction command, status, and limitations.

Runnable code belongs in `src/` or `apps/` when introduced. Link to it rather than duplicating code here. Keep large or sensitive outputs in appropriate external storage with a committed manifest. Don't commit build caches.
