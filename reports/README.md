# Reports

Keep reports and their editable source here. When a report needs several files, use a named folder and record the question, evidence links, generation command, and draft/verified/accepted status. Link the authoritative version rather than scattering copies.

## Starter distribution reports

- [Harness workflow review](harness-workflow-review.md): ten source sections, original diagrams, adaptations, and implementation evidence.
- [Website research](website-research.md): purpose, repository shape, background, source and component provenance.
- [Website verification](website-verification.md): local routes, behavior, design review, and remaining release boundaries.
- [Original objective assessment](starter-objective-assessment.md): historical evaluation before template isolation.

- [Essay copy and claim review](why-starter-copy-review.md): sentence/paragraph purpose, sources, implementation support, and proposed revisions; includes all interactive copy states.

- [Essay rewrite and justification](why-starter-copy-rewrite.md): applied copy changes, paragraph sources, and local verification.
